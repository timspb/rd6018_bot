
## MAIN HMI — Imin confirmation (2026-11-01)

А` / `⏳`, без сообщения об успешном завершении условия.
- [ ] Раздельно отображать: наблюдаемый минимум тока и время после него; plateau и его выдержку для MAIN→MIX; tail-current и выдержку завершения MAIN. Использовать существующие источники истины, без второго детектора.
