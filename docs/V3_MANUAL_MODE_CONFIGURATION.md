# V3 Manual mode configuration

Ручной режим теперь имеет один обязательный маршрут `MAIN → MIX`. Его параметры
хранятся в `config/charge/manual.yaml`; Python-код не содержит пользовательских
уставок этих двух стадий.

`MAIN` задаёт ток, напряжение, подтверждённый нижний порог тока и выдержку после
подтверждения минимума. После подтверждения и окончания выдержки runtime переводит
сессию на `MIX`.

`MIX` задаёт отдельные ток и напряжение, `delta_voltage_v`, `delta_current_a` и
выдержку после подтверждения delta. В CV используется ΔI, в CC — ΔV. Safety,
readback и verified-OFF остаются владельцами существующего runtime safety path.

Ввод старой однострочной формы `V I [condition]` отключён на production middleware.
Запуск настроенного маршрута выполняется командой `MANUAL`. Парсер старой формы
сохранён только как внутренняя compatibility-функция для чтения старых тестов и
исторических данных; он не является входом production Manual.
