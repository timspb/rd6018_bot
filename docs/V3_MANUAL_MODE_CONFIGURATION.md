# V3 Manual mode configuration

Ручной режим имеет один обязательный маршрут `MAIN → MIX`. Он не выбирается
по напряжению и не является скрытым `CUSTOM → CALCIUM` режимом. Все рабочие
параметры находятся в `config/charge/manual.yaml`; Python-код содержит только
модель, валидацию и исполнение переходов.

## Поля конфигурации

### MAIN

- `voltage_v` — напряжение заряда, В;
- `current_a` — ток заряда, А;
- `minimum_current_a` — нижний порог тока, А;
- `confirmation_count` — число подтверждений минимума;
- `confirmation_interval_seconds` — интервал между подтверждениями;
- `hold_seconds` — выдержка после подтверждения минимума.

В MAIN нет delta-параметров. Нижний порог сначала подтверждается, затем
выдерживается заданное время.

### MIX

- `voltage_v` — напряжение заряда, В;
- `current_a` — ограниченный ток заряда, А;
- `delta_voltage_v` — ΔV для CC, В;
- `delta_current_a` — ΔI для CV, А;
- `confirmation_count` — число подтверждений delta;
- `confirmation_interval_seconds` — интервал между подтверждениями;
- `hold_seconds` — выдержка после подтверждения delta.

Оба delta обязательны: в CC применяется ΔV, в CV применяется ΔI.

## Порядок работы

```text
MANUAL
  ↓
MAIN: V/I → Imin → подтверждение → MAIN hold
  ↓
MIX: отдельные V/I → ΔV или ΔI → подтверждение → MIX hold
  ↓
завершение через существующий verified-OFF/safety path
```

`MAIN` задаёт ток, напряжение, подтверждённый нижний порог тока и выдержку после
подтверждения минимума. После подтверждения и окончания выдержки runtime переводит
сессию на `MIX`.

`MIX` задаёт отдельные ток и напряжение, `delta_voltage_v`, `delta_current_a` и
выдержку после подтверждения delta. В CV используется ΔI, в CC — ΔV. Safety,
readback и verified-OFF остаются владельцами существующего runtime safety path.

После изменения YAML требуется контролируемый перезапуск приложения. Сохранённая
активная сессия не возобновляется автоматически: требуется повторная авторизация
и новый safety/readback transaction.

Значения должны оставаться внутри общего manual envelope и ограничений
оборудования. Нельзя повышать их ради обхода Safety.

Для записи параметров оператор отправляет две строки:

```text
MAIN: U=14.7 I=5.0 Imin=0.30 hold=600
MIX: U=16.5 I=1.5 dV=0.03 dI=0.03 hold=7200
```

Парсер валидирует значения, атомарно записывает их в `config/charge/manual.yaml`,
а затем создаёт запрос из записанного профиля. `hold` задаётся в секундах; для
формата времени допускается `H:MM` или `H:MM:SS`. Команда `MANUAL` запускает
последний сохранённый профиль без изменения его значений.

Старый формат одной строки `V I [condition]` отключён на production middleware и
не может запустить ручной режим. Внутренняя compatibility-функция сохранена
только для чтения старых тестов и исторических данных; production-входом она не
является.
