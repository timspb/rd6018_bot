## P1 instrument qualification (before any battery trial)
Freeze instrument IDs, range, firmware, calibration date, reference traceability and expanded uncertainties; test U at 10.5,12,14V and across intended approved range, I at zero and representative fractions of range in both directions, time against reference clock, T against reference thermometer at low/nominal/high operating range, with repeated readings, drift and offset recorded. Use calibrated reference equipment/dummy load; never use an intentional battery short. Verify terminal Kelvin voltage, current sign, timestamp synchrony, sampling gaps, independent hardware shutdown and no simultaneous charge/load except separately designed controlled test. Separate battery temperature and surface/ambient proxy, sensor location/lag; unknown internal T stays unknown. GOST tolerances assessed by absolute error plus expanded calibration uncertainty; for 72Ah example I20=3.6A, ±30mA is 0.833%/0.6Ah over20h (bound only). Proposed research targets U≤10mV, I≤10mA at3.6A, timing≤1s over20h, battery T uncertainty≤0.5°C; actual qualification not established. No claim 10mV resolves CDF without noise/bandwidth qualification.
Data contract: specimen ID, construction, label capacity/rate/cutoff, charge procedure/version/history, rest, terminal V, signed I (positive into battery), Tsurface/Tambient/Tbattery if validated, monotonic timestamp and wall clock, state/load event and validity flags, calibrated ranges, raw unrounded readings; independent raw archive; Q_in,Q_out,W_in,W_out separately, net derived. Record missing/duplicate samples, faults, calibration failure, reason for termination. No silent interpolation over gap. Log steady reference test at ≥1Hz research target, measured cutoff event before current removed, max gap2s during valid interval; higher bandwidth pilot for transients. If early hardware stop or missing endpoint, Q is censored/partial, not reference capacity. Do not delay hardware cutoff to obtain a reading. 
## P2 design and decision criteria
Before running: select exact model, approved full-charge preparation, standardized temperature/rest/rate/cutoff, stop limits from applicable documentation, reference equipment certificates and sample allocation. Control group ordinary manufacturer-approved charge, independent battery-level matched groups; for metrology pilot use at least 3 intact specimens of same model, at least 2 repeats per unit only if safe; repeatability is measurement+conditioning, not pure instrument noise. Keep first and subsequent Q, never select only best. No reuse of an aged battery with suspected short or weak-cell anomaly in full discharge. Independent load-side instrument versus reference shunt and terminal voltmeter. Stop for unsafe T/voltage/individual-cell limits, telemetry/actuator discrepancy, physical damage; no deliberate short/reversal, no VRLA opening. If reference invalid, label INVALID or PARTIAL and report why; no extrapolated C20. Offline validator verifies illustrative bounded U/I/T/current stability, time gaps, endpoint and no use of OFF rebound. Difference between nominal-I*time and measured integral reported separately; Wh integrate exact piecewise linear product. Uncertainty includes calibration, drift, sampling, cutoff slope, repeatability and T; correlated systematic terms not treated as independent. For before/after u_delta=sqrt(u_before²+u_after²−2cov); guard bands/coverage per NIST TN1297 https://www.nist.gov/pml/nist-technical-note-1297/nist-tn-1297-6-expanded-uncertainty. Predeclare meaningful effect (illustrative screening delta=5% rated Ah, not universal), distinguish meaningful improvement if lower interval>delta, deterioration if upper<−delta, practical equivalence if interval inside ±delta, else INCONCLUSIVE. Separate metrology from biological variation and controls; no physical execution or actual calibration implied. Document P-R11 design ready for independent review; acceptance P not promoted pending review and equipment qualification criteria verification.
## P3/P4/P5 design dependencies and future load
P3-R05/CDF: at fixed T, matched starting SOC/charge history, randomize rest windows e.g.10min/1h/4h/24h as research arms, reset preconditioning between probes; short discharge under model-permitted envelope, record 10Hz or better pilot around transition and 1Hz long interval, validate actual time response and noise (not assumed BV-600 performance). Define initial ohmic jump, trough time/voltage, recovery amplitude, plateau and ambiguity; separate rest-induced voltage drift and charge history, do not count repeats as independent specimens. CDF is not a MAIN/MIX stop trigger; optional post-charge discharge observation, compare independently measured Q and baseline OCV/T/Rdc. No induced weak cell. R06 EIS separate qualified instrumentation. R12 battery-held-out validation with baseline, coverage and false reassurance. R13 noninvasive rest/retained Q, no induced short. 
P4: isolate charge history, matched ordinary-charge control, separate equal elapsed time/equal net Ah/equal functional endpoint estimands; use safety endpoints and construction-specific profiles only. P5: matched control, independent pre/post reference Q at identical conditions, calendar and cumulative Ah/EFC followups, all failures/withdrawals included. Sample size estimated from independent pilot variance; prespecify threshold and power, not number of logs. Laboratory material endpoints SEM/XRD/phase/contact independent, no field modification.
