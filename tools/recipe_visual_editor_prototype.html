U max / I max — только локальные пределы предварительной проверки, не реальные ограничения контроллера. Итоговую проверку исполняемости выполняет сервер. Версия и ID действуют только при экспорте SET/OFF/WAIT; импорт штатных этапов не превращает их в простые команды.
